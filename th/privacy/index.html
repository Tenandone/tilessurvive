สถิติการใช้งานและความเป็นส่วนตัว

เราใช้การตั้งค่าการวัดผลแบบเดียวกันที่ลดการเก็บข้อมูลส่วนบุคคลในทั้ง 21 ภาษา การอ่านคู่มือและใช้เครื่องมือไม่ต้องสมัครสมาชิก ระบุชื่อจริง หรือให้ข้อมูลติดต่อ

อัปเดตล่าสุด 2026-11-06

สิ่งที่เราวัดผล

GA4 (G-Z2MJ6TXZHK) วัดยอดดูหน้าเว็บ ภาษา ประเทศโดยประมาณ การใช้เครื่องมือ การคัดลอกรหัสของขวัญเกม และการคลิกลิงก์ TEN เหตุการณ์จำกัดตามรายการที่อนุญาตไว้อย่างชัดเจน พารามิเตอร์ไม่รวมข้อความค้นหาหรือส่วนย่อยของ URL แบบดิบ ข้อมูลที่กรอกในเครื่องคำนวณหรือแบบฟอร์ม และ URL ภายนอกแบบเต็ม

สัญญาณที่ไม่ใช้คุกกี้

สถานะความยินยอมด้านการวิเคราะห์และโฆษณาเริ่มต้นเป็นปฏิเสธ และจะไม่เปลี่ยนเป็นยินยอมโดยอัตโนมัติ อย่างไรก็ตาม GA4 ยังอาจส่งสัญญาณที่ไม่ใช้คุกกี้ รวมถึงข้อมูลทางเทคนิคของคำขอ เว็บไซต์ไม่สร้างโปรไฟล์ผู้เข้าชมรายบุคคลหรือตัวระบุถาวรสำหรับการวิเคราะห์ของตนเอง

การประมวลผลที่อยู่ IP

Google และโครงสร้างพื้นฐานโฮสติ้งประมวลผลที่อยู่ IP เพื่อจัดการคำขอ Google ระบุว่าจะทิ้ง IP จากสหภาพยุโรป สวิตเซอร์แลนด์ และสหราชอาณาจักรหลังจากระบุตำแหน่งโดยประมาณแล้ว ในภูมิภาคอื่น Google ใช้ IP สำหรับบริการพื้นฐาน และบริการโฆษณาที่เชื่อมโยงอาจใช้ IP ที่เข้ารหัสตามการตั้งค่า การไม่ใช้คุกกี้ไม่ได้แปลว่าไม่มีการส่งหรือประมวลผลข้อมูล

หยุดหรือกลับมาส่งสถิติ

ปุ่มด้านล่างใช้หยุดหรือกลับมาส่งข้อมูลของเว็บไซต์ไปยัง GA4 ในเบราว์เซอร์นี้ การตั้งค่าถูกบันทึกไว้ที่นี่เท่านั้นและไม่รับช่วงบันทึกความยินยอมเดิม การกลับมาส่งไม่เปลี่ยนสถานะเป็นยินยอม หากเปิด GPC หรือ DNT การส่งจะยังคงหยุดอยู่ ความยินยอมโฆษณาและแผนที่บันทึกในเครื่องมือจะไม่เปลี่ยนแปลง

Google และบริการอื่น

Search Console ให้ข้อมูลประสิทธิภาพการค้นหาบน Google แบบรวม ซึ่งแยกจากการใช้งานภายในเว็บไซต์ GA4, GitHub Pages และ AdSense ประมวลผลข้อมูลตามข้อกำหนดของแต่ละบริการ ความยินยอมโฆษณาที่จำเป็นและตัวเลือก CMP ยังคงมีอยู่ ประกาศนี้ไม่ได้ระบุว่าทั้งเว็บไซต์หรือผู้ให้บริการเหล่านี้ไม่ใช้คุกกี้เลย

ความหมายของตัวเลข

จำนวนครั้งและค่าประมาณจากแบบจำลองไม่ใช่จำนวนผู้เข้าชมที่ไม่ซ้ำกันอย่างแม่นยำ การบล็อก ความผิดพลาดของเครือข่าย และวิธีรายงานอาจทำให้ข้อมูลขาดหาย การคลิก TEN ไม่ใช่หลักฐานการซื้อ เราไม่สร้างสถิติย้อนหลังที่ขาดหายขึ้นเอง
