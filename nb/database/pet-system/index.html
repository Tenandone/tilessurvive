Kjæledyroversikt

Kjæledyrsystemet lar høvdinger få kjæledyregg fra kjæledyrrelaterte etterretningsoppdrag, klekke og utvikle kjæledyr og bruke dem som støtte for heltelag.

Hvert lag kan ha med ett kjæledyr uten å erstatte en helt. Offisiell kjæledyrveiledning

  • Dupliserte kjæledyr blir til eksklusive avtrykk som brukes til trening, øker bonusratene og låser opp ferdigheter.
  • Kjæledyrenes egenskapsbonuser gjelder alle helter, uansett om kjæledyret er satt inn. Hvert kjæledyr kan bare være på ett lag om gangen.
  • Ufullførte kjæledyroppdrag oppdateres neste dag. Fullførte oppdrag med uavhentede belønninger beholdes i opptil 3 dager.
