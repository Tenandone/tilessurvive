Sykehusregler

Veiledning til behandling og kapasitet

  1. Sykehuskapasiteten øker når sykehusets nivå stiger.
  2. Bare alvorlig sårede tropper legges inn på sykehuset for behandling. Lett sårede tropper blir friske straks de vender tilbake til basen.
  3. Følg nøye med på sykehusets maksimale kapasitet. Hvis antall alvorlig sårede tropper overstiger kapasiteten slik at de ikke kan behandles, dør de umiddelbart.
  4. Alvorlig sårede tropper som er under behandling, kan ikke avskjediges.
  5. Hvis du har gratis behandling igjen, viser sykehuset bare troppene som kan behandles gratis. Når all gratis behandling er brukt opp, vises de resterende troppene.
  6. Gratis behandling kan ikke brukes i Reservoarraid.
