Tiles Survive-cadeaucodes inwisselen

Volg deze stappen als je voor het eerst een code inwisselt.

  1. Open het spel en ga naar Profiel → Instellingen → Pakketuitwisseling.
  2. Voer de Tiles Survive-cadeaucode exact in zoals vermeld, inclusief hoofdletters en kleine letters.
  3. Controleer na het inwisselen je postvak of beloningsscherm om de voorwerpen te ontvangen.

Veelgestelde vragen over Tiles Survive-cadeaucodes

Veelgestelde vragen.

Waar voer ik Tiles Survive-codes in?
Je kunt ze invoeren in het menu Pakketuitwisseling onder Profiel Instellingen in het spel.
Hoe herken ik het verschil tussen permanente en tijdelijke codes?
Permanente codes staan afzonderlijk vermeld, terwijl tijdelijke codes als actief of verlopen zijn ingedeeld.
Wat moet ik controleren als een code niet werkt?
Controleer de exacte spelling en hoofdletters, de vervaldatum, de limiet van één keer per account en een eventueel vereist minimumniveau.
Kan ik ook verlopen codes bekijken?
Ja. Onderaan deze pagina vind je het overzicht van verlopen codes.
