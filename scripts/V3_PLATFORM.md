# V3 플랫폼 운영·재생성 안내

이 문서는 21개 언어의 기존 페이지에 추가한 V3 성장 계획, 개인 이벤트 일정, 통합 검색, 제휴 안내 및 분석 동의 기능의 유지보수 기준이다. 운영 배포 여부와 실제 HTTP 결과는 해당 릴리스의 별도 검증 기록으로 확인한다. 이 파일 자체는 배포 성공 증명이 아니다.

보관 클라이언트의 적용 범위는 2.6.200, build 1512다. 빌드 실행일을 게임 내 검증일로 쓰지 않는다. 현재 서버에서 확인하지 않은 규칙을 최신 확정 규칙으로 표시하지 않는다. 아랍어·베트남어·노르웨이어에 확보하지 못한 공식 원문을 만들어 넣거나 편집 번역을 공식 명칭으로 바꾸지 않는다.

게임 원본 값 변경이 필요한 경우에는 같은 버전·ID·레벨 전이·rank·프로필·단위를 먼저 대조한다. 변경 전 원문과 old/new 차이, 이유 및 출처는 공개 저장소 밖의 릴리스 원장에 남긴다. 빈 특수재료 목록이나 누락 값을 임의로 채우지 않는다.

## 생성 순서와 소유권

`scripts/build-v3-platform.js`는 기존 URL에 V3 관리 영역을 투영한다. HTML의 `data-v3-owned`와 `TS_V3_*` 표시는 생성기 소유 범위를 뜻한다. 이 안을 직접 편집하면 재생성 시 사라지거나 소유권 검사가 실패할 수 있다. 화면 문구·구조는 해당 생성기와 언어별 문구 파일에서 고친다.

검색은 `js/v3-search-core.js`의 공통 순위 로직을 본문 검색과 헤더 추천이 사용한다. 공통 코어는 `platform-search.js`, `product-30.js`보다 먼저 실행되어야 한다. 원래 검색 인덱스를 갱신한 뒤 V3 파생 인덱스를 생성한다.

```powershell
npm ci
npm run build:v3
```

`build:v3`는 V3 검색 파생물 생성 후 V3 HTML 투영을 수행한다. 이번 릴리스의 운영 반영은 검토한 기존 21언어 입력 위에서 이 좁은 투영을 사용한다. 아래 전체 파이프라인은 생성된 HTML과 여러 파생 데이터를 다시 쓰므로 별도의 작업 복제본에서 검증한다.

```powershell
npm run build
```

전체 legacy/50 파이프라인에는 오래된 사이트맵 생성 단계가 포함되어 있다. 이번 격리 검사에서 기존 다국어 URL 목록을 축소하는 동작이 관측되었으므로, 이 명령은 현재 운영 배포용 생성 명령으로 간주하지 않는다. 종료 코드 0만으로 운영 원장 보존을 보장하지 않는다. 격리 전체 빌드의 HTML·검색·사이트맵을 운영 후보로 통째로 복사하지 말고, 최종 21언어 정규 URL·원본·V3 소유권 대조와 글로벌 재생성 범위를 별도로 검증한다.

현재 `npm run build`의 `postbuild`, `npm run build:building-system`의 `postbuild:building-system`, `npm run build:global:release`의 `postbuild:global:release`는 마지막에 `build:v3`를 실행한다. npm 명령 대신 하위 Node 스크립트를 직접 실행하면 npm 후처리가 실행되지 않는다. `build:calendar`, `build:power-plant:unified` 등 V3 후처리가 없는 일부 대상 빌드를 직접 실행한 경우에도 마지막에 `npm run build:v3`를 실행한다.

전역 번역기는 검토된 V3 소유 블록을 일반 본문으로 재번역하지 않고 해당 언어의 소유 렌더러로 복원한다. 단순히 누락 문자열을 무시하거나 오래된 출력에 덧붙여 통과시키지 않는다. 두 번째 V3 투영이 첫 번째와 동일해야 하며, 캐시 버전은 현재 JS/CSS 해시를 가리켜야 한다.

## 성장 계획의 계산 범위

발전소의 기존 건물 계산기 DOM과 수치 코어를 재사용한다. 단계 합계는 `현재 레벨 < 행의 레벨 ≤ 목표 레벨`의 A 원자료를 합산한다.

```text
부족량 = max(0, 원자료 자원 합계 − 보유 자원)
잔여 시간 = max(0, 기본 시간 합 − 입력한 보너스 단축 분×60 − 가속 분×60)
```

건설 속도 보너스의 중첩 공식을 새로 추측하지 않는다. 사용자가 게임에서 확인한 총 단축 시간을 분으로 입력한다. 선행 건물의 현재 레벨/단계는 미입력·충족·미충족으로 표시한다. 선행 건물 자체의 업그레이드 비용, 대기열, 미래 수입 및 서버 완료 시각은 계산에 포함하지 않는다.

계획 저장키는 `tiles.v3.powerPlan.1`이다. 명시적인 URL 입력은 저장 계획보다 우선한다. 잘못된 저장 값은 전체 검증 후 거부하고 일부 조건만 먼저 반영하지 않는다. 초기화는 이 계획의 저장키만 지운다. 공유 URL에는 입력한 계획이 포함되므로 계정 식별자나 비밀번호를 이 상태에 추가하지 않는다. 클립보드가 거절되면 선택 가능한 텍스트를 표시한다.

## 개인 이벤트 일정

기존 자료는 이벤트 3종·참고 프로필 7개다. 현재 확정된 서버 일정은 0개이며 원래의 `confirmedAnchorUtc`는 모두 `null`이다. 사용자가 넣은 일회성 시작·종료 시각을 현재/예정/종료 상태와 카운트다운으로 보여 준다. 이를 공식 일정으로 승격하지 않는다.

사용자 선택 오프셋은 UTC −14:00~+14:00, 15분 단위다. 실제 게임 서버의 시간대를 자동 탐지하지 않는다. 브라우저 저장키는 `ts-v3-event-plans-v1`, 저장 가능한 개인 일정은 최대 20개다. 계정 동기화·푸시 알림·자동 반복 확정은 없다. 새로운 공식 일정을 추가하려면 이벤트/프로필, 서버 적용 범위, UTC 시각, 근거와 확인일을 확보하고 별도로 검증한다.

## 제휴 링크와 GA4

모든 언어의 제휴 목적지는 다음 주소 그대로 유지한다.

```text
https://www.lootbar.com/ko/shop/ten/top-up/tiles-survive
```

언어 경로나 추적 매개변수를 추측해 바꾸지 않는다. 확정되지 않은 할인·안전·TEN 전용 혜택을 광고하지 않는다. 부족 자원과 실제 판매 상품의 관계가 검증되지 않았다면 상품을 자동 추천하지 않는다. 무료 성장 경로를 함께 제공하며 클릭을 구매나 수익으로 기록하지 않는다.

`scripts/v3-affiliate-content.js`의 `transformAnalytics`가 기존 GA 부트스트랩을 동의 기본 거절 상태로 옮긴다. `js/v3-affiliate.js`만 V3 제휴 측정의 소유자다. 기존 두 제휴 트래커는 V3 표식에서 중단하여 같은 클릭을 다시 보내지 않는다.

| 측정 ID | 보존 범위 |
| --- | --- |
| `G-Z2MJ6TXZHK` | 주 측정 ID. V3 사용자 정의 제휴/기능 이벤트의 명시적 `send_to` 대상. |
| `G-TMGDGSEWW6` | 기존 21언어 쿠폰 및 할인 프로모션 안내 42페이지에서만 유지. |
| `G-Z2MJ6TZXHK` | 기존 중문 간체/번체 홈 2페이지에서만 유지. 주 ID와 비슷해도 오타로 단정해 바꾸지 않는다. |

페이지별 실제 ID 목록은 부트스트랩의 `TS_V3_GA_IDS`에 보존한다. 동의 전에는 GA 라이브러리·기존 config·GA preconnect가 실행되지 않는다. 허용 후 단일 라이브러리로 해당 페이지의 ID만 초기화하고 각 ID에 문서당 `page_view` 한 번을 보낸다. 모든 자체 이벤트의 `page_location`은 정적 canonical 경로이며 referrer는 전체 URL 대신 출처 범주로 제한한다. 검색어·query/hash·입력값·게임 UID·주문번호를 이벤트에 추가하지 않는다.

알려지지 않은 ID, 동적 config, 광고/CMP와 합쳐진 미검토 스크립트를 만나면 생성은 실패한다. 무조건 삭제하거나 허용 목록에 넣지 말고 원래 용도부터 확인한다. GA4 연결로 해당 속성의 존재·소유권이 확인된 것으로 간주하지 않는다.

동의 저장키는 `tiles.v3.analyticsConsent`, 값은 `granted` 또는 `denied`다. 허용/거절은 `TS_V3_AFFILIATE.setConsent(boolean)`을 사용한다. 기본 상태는 거절이며 도구 기능을 잠그지 않는다. 다른 상세 페이지에서도 같은 선택이 적용되어야 한다. AdSense 및 CMP 코드는 별도 소유 영역이며 제거하지 않는다.

`send_page_view:false`는 초기 config의 자동 전송을 끈다. GA4 속성의 Enhanced Measurement가 history 변경을 별도로 감지하는지는 속성에서 확인해야 한다. 정적 코드 테스트만으로 원격 자동 측정 설정이나 실제 전송·매출을 검증했다고 말하지 않는다. [Google 동의 모드](https://developers.google.com/tag-platform/security/guides/consent), [Google page_view 설정](https://developers.google.com/analytics/devguides/collection/ga4/views)을 참고한다.

## QA와 공개 전 확인

```powershell
npm run test:v3
npm run test:global
npm run test:power-plant:unified
node --test scripts/test-building-system.js scripts/test-building-dependencies.js
node --test --test-name-pattern="all other 119 frozen" scripts/test-power-plant-global-rebuild.js
```

테스트는 다음을 서로 다른 분모로 확인한다.

- 기존 104개 게임/참조 파일과 추가 승인 발전소 모델·선행 핀 2개 보존. Windows 줄바꿈은 LF로 정규화하되 다른 본문 공백을 임의로 정규화하지 않는다.
- 21언어 2,520 canonical 콘텐츠, 2,537개 언어별 `index.html`의 SEO·상속 본문·광고·모델·V3 소유권. 이 수치는 전체 HTML 파일 수와 다르다.
- 기존 검색 9,175개 레코드와 URL/앵커, 동음이의 항목의 ID·문맥 분리, 공식/편집 번역의 구분.
- 미래 생성 경로 3개×14언어의 번역 누락·모델 수치·소유권·멱등성. 별도로 동결된 V3 이전 영어 119경로×14언어의 이전/현재 번역 엔진 출력 비교.
- 알려진 부가 GA 44페이지의 ID 보존, 동의 전 로더 없음, 거절·철회, 사용자 정의 이벤트의 주 ID 단일 전송, 미확인 ID 실패 처리.

2026-11-04 기준 기존 Aegis 공통 렌더러의 멱등성 실패는 정상 기준 커밋에서도 관측되었고 미해결 상태로 기록했다. 기존 건물 검사의 이 1건을 신규 회귀와 구분하되, 테스트를 삭제하거나 결과를 전부 통과한 것처럼 표기하지 않는다.

실제 PC·모바일에서는 검색→상세→성장 계획, 숫자·선행 조건, 잘못된 입력 복구, 저장·새로고침·언어 전환·공유, 개인 이벤트 시간대, 충전 문답과 TEN 링크, 분석 거절 후 상세/쿠폰 이동을 확인한다. 자동완성처럼 지연 실행되는 UI는 결과가 실제로 나타난 뒤 판정한다. DOM/VM 테스트는 브라우저 검증의 대체물이 아니다.

배포 전 전체 빌드는 격리 복제본에서 실행하고 정상 종료, 생성 결과, 원본/SEO/광고 보존을 별도로 확인한다. 검증하지 않은 생성물 전체를 원래 작업 트리에 복사하지 않는다. 배포 후에는 Pages 상태와 정확한 커밋, 운영 HTTPS 응답, 본문/자산 해시와 핵심 사용자 흐름을 다시 확인한다. 미실행 단계는 완료로 표시하지 않는다.

## 롤백

V3 착수 기준은 `c1d9151593f621249338409c6fcbc8972f0514a5`다. 작업 브랜치는 `codex/global-platform-v3`, 당시 로컬 복구 기준 브랜치는 `codex/v3-baseline-20261104`다. 복구 브랜치가 존재하는 것과 운영 롤백을 실행한 것은 다르다.

문제가 발생하면 현재 변경을 보존한 별도 브랜치에서 배포 커밋의 revert 또는 검증된 정상 트리 복원 커밋을 준비한다. 작업 중인 파일을 덮거나 main에 강제 푸시하지 않는다. 복원 커밋의 데이터·계산·광고·SEO·언어·TEN 링크를 검사하고 배포한 뒤 Pages 및 실제 운영 URL을 다시 검증한다. 롤백 후에도 장애 내용, 영향 범위와 수정 전후 근거는 비공개 릴리스 기록에 보존한다.

이 문서는 `scripts/`에 있어 Jekyll 웹사이트 배포 대상에서 제외된다. 로컬 계정 경로·접근 오류 원문·비공개 감사 자료·구매 자료는 이 문서나 공개 저장소에 추가하지 않는다.
