LootBar 충전 전 확인 가이드

게임 내 상점과 조건을 비교하세요. 구매는 선택입니다.

LootBar는 어떤 서비스인가요?

게임 충전을 취급하는 외부 마켓플레이스입니다. TilesSurvive.net은 독립 안내 사이트이며 주문을 처리하지 않습니다.

게임 내 결제와 무엇이 다른가요?

가격·결제·지급은 LootBar의 판매 조건을 따릅니다. 같은 패키지와 최종 결제액을 비교하세요.

Self-TopUp은 무엇인가요?

LootBar가 안내하는 방식으로, 해당 인터페이스에서 게임에 로그인하여 구매한 패키지를 수령합니다.

어떤 순서로 진행하나요?

상품과 이용 조건 확인 → LootBar에서 결제 → Self-TopUp 안내 진행 → 게임에서 지급 확인 순서입니다.

어느 국가와 결제수단을 지원하나요?

결제 화면에서 지역과 서버를 확인하세요. LootBar는 Visa·직불카드·전자지갑을 안내하지만 실제 이용 가능 여부는 다릅니다.

어떤 계정 정보가 필요한가요?

LootBar의 현재 절차에는 LootBar 계정과 게임 로그인이 필요할 수 있습니다. LootBar의 현재 로그인 안내를 따르세요. 이 사이트는 게임 비밀번호·인증코드·결제정보를 요구하지 않습니다.

문제가 생기면 어디에 문의하나요?

주문번호와 오류 화면을 준비해 LootBar 고객지원에 문의하세요. 비밀번호나 인증코드를 상담원에게 보내지 마세요.

TEN 링크에 어떤 혜택이 있나요?

조건을 충족한 구매는 이 사이트 운영에 도움이 될 수 있습니다. 확인된 구매자 전용 추가 혜택은 없으므로 결제 전 현재 조건을 확인하세요.

3단계 충전 방법

패키지 선택

LootBar를 열고 현재 표시되는 타일서바이벌 패키지 중 계획에 맞는 상품을 선택합니다.

현재 계정 절차 진행

상품과 이용 조건 확인 → LootBar에서 결제 → Self-TopUp 안내 진행 → 게임에서 지급 확인 순서입니다.

게임에서 지급 확인

영수증을 보관하고 구매한 패키지가 게임에 정상 지급됐는지 확인합니다.

다음 충전 전에 이 페이지를 즐겨찾기하세요

다음 충전 시에도 같은 제휴 링크를 열 수 있도록 이 페이지를 다시 이용하세요. 즐겨찾기는 적격 여부나 리워드를 보장하지 않습니다.

브라우저의 즐겨찾기 기능을 사용하세요. Windows는 보통 Ctrl+D, macOS는 Cmd+D입니다.

결제 전 확인

  • 게임, 패키지, 지역, 통화와 최종 가격을 확인하세요.
  • 현재 LootBar 결제 절차에서 요구하는 정보만 입력하세요.
  • 지급 시간과 결제 수단은 달라질 수 있으며 거래 문제는 LootBar 고객지원에서 처리합니다.
  • 제3자 제휴 서비스이며 게임 공식 결제 페이지가 아닙니다.
  • 적격 제휴 구매는 사이트 운영에 도움이 될 수 있습니다.

이 페이지에는 제휴 링크가 포함되어 있습니다. 적격 구매가 발생하면 TilesSurvive.net이 수수료를 받을 수 있습니다. 결제, 가격과 리워드는 제휴 서비스가 관리합니다. 제휴 공개

충전 FAQ

왜 이 페이지를 즐겨찾기해야 하나요?

다음 충전 때 같은 제휴 링크를 쉽게 다시 열기 위해서입니다. 즐겨찾기 자체가 추적이나 리워드를 보장하지 않습니다.

결제 또는 지급 문제는 어디에 문의하나요?

결제, 지급과 고객지원은 LootBar가 담당합니다. 영수증을 보관하고 LootBar 고객지원에 문의하세요.
