타일서바이벌 기프트코드 입력 방법

처음 입력하는 경우 아래 순서대로 진행하면 됩니다.

  1. 게임에 접속한 뒤 프로필 → 설정 → 패키지교환 메뉴로 이동합니다.
  2. 타일서바이벌 기프트코드를 대소문자 그대로 입력합니다.
  3. 등록 후 우편함 또는 보상 수령 화면에서 아이템을 확인합니다.

타일서바이벌 기프트코드 FAQ

자주 묻는 질문입니다.

타일서바이벌 코드는 어디서 입력하나요?
게임 내 프로필 설정의 패키지교환 메뉴에서 입력하면 됩니다.
무기한 코드와 기간제 코드는 어떻게 구분하나요?
상시 코드는 무기한 코드로 따로 표시되고, 기간이 있는 코드는 활성 코드 또는 만료 코드로 구분됩니다.
코드가 적용되지 않을 때는 무엇을 확인해야 하나요?
대소문자, 만료 여부, 계정당 1회 제한, 최소 레벨 조건을 먼저 확인하세요.
만료된 코드도 확인할 수 있나요?
