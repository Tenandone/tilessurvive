이벤트 도우미

이벤트 일정과 준비할 자원, 추천 행동을 정리해 효율적으로 보상을 챙길 수 있도록 도와드립니다.

이벤트 데이터는 실제 게임 진행 상황에 맞춰 계속 보완됩니다.

빠른 요약

오늘 확인할 이벤트, 준비 자원, 추천 행동을 먼저 정리하세요.

오늘 확인할 것

  • 진행 중인 이벤트
  • 오늘 소모해도 되는 자원
  • 보상 마감 시간

준비할 자원

  • 가속권
  • 영웅 조각
  • 스킬북
  • 장비 재료
  • 훈련/연구/건설 자원

추천 행동

  • 이벤트가 겹칠 때 자원 사용
  • 단독 이벤트에는 최소 소모
  • 보상 단계 확인 후 사용

이벤트 타입별 준비표

이벤트 타입에 따라 먼저 확인할 항목과 추천 행동이 달라집니다.

이벤트 타입확인할 것추천 행동
건설 이벤트건설 가속, 건설 자원, 마감 시간다른 성장 이벤트와 겹칠 때 건설 가속을 집중 사용
연구 이벤트연구 가속, 연구 자원, 연구 완료 타이밍연구 완료 시간을 이벤트 기간 안에 맞추기
훈련 이벤트병사 훈련 수량, 훈련 가속, 병종별 소모 자원훈련 완료를 이벤트 기간에 맞춰 보상 단계 확보
영웅 성장 이벤트영웅 조각, 경험치 아이템, 스킬북조각과 스킬북은 이벤트가 겹칠 때 사용
장비 강화 이벤트장비 재료, 강화 재료, 보상 단계재료를 평소에 모아두고 이벤트 기간에 집중 사용
소환 이벤트소환권, 무료 소환 시간, 누적 보상무료 소환은 챙기고 소환권은 보상 단계 기준으로 사용

자원을 지금 써도 될까?

이벤트가 1개만 진행 중이면 최소 사용
성장/소모 이벤트가 겹치면 집중 사용
다음 보상 단계까지 필요한 수량을 먼저 확인
보상 단계 달성이 어렵다면 자원 보존
서버 초기에는 성장을 우선하되, 중후반에는 이벤트 효율을 우선

이벤트 준비 체크리스트

✓현재 진행 중인 이벤트 확인
✓다음 보상 단계까지 필요한 점수 확인
✓사용할 자원 종류 확인
✓가속권/조각/스킬북/장비 재료 보유량 확인
✓이벤트 종료 시간 확인
✓보상 수령 여부 확인

안내

  • 이 도구는 팬 커뮤니티용 참고 자료입니다.
  • 실제 이벤트 명칭, 보상, 일정은 서버와 업데이트에 따라 달라질 수 있습니다.
  • 중요한 자원은 사용 전 게임 내 이벤트 화면을 한 번 더 확인하세요.
