민가

민가는 생존자의 휴식 공간입니다. 시설을 업그레이드하면 수면 품질이 향상되고 생존자의 수면도가 증가합니다.

← 건물 전체 목록레벨별 요구량성장 계획과 활용함께 볼 건물과 공략

성장 계획과 활용

생존자의 수면 상태와 개선할 민가 번호를 확인하세요. 같은 레벨이어도 다른 민가의 비용으로 계산하지 말고 해당 민가를 선택하세요.

업그레이드 전 확인

개선할 민가의 번호와 건설 조건을 확인하세요. 여러 민가를 함께 올린다면 각 민가에 필요한 자원과 시간을 따로 계산해 합산하세요.

레벨별 요구량

Lv.1–10

각 레벨의 업그레이드에 필요한 기본 자원과 시간입니다.

게임의 Lv.2 기본 수치와 일치하는 표를 선택하세요.
