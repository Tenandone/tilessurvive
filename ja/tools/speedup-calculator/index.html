Tiles Survive 加速計算機

加速アイテムの日数、時間、分を合算し、イベントで使う前に総時間を確認できます。

この計算機は加速時間の合算と単位変換用であり、イベントスコア公式の計算機ではありません。

加速時間を入力

空欄は 0 として扱い、負数や不正な値は 0 に補正します。

FAQ

この計算機は何を計算しますか

加速アイテムの日数、時間、分を合算し、総分、総時間、日数と時間と分の内訳で表示します。

イベントスコアも計算しますか

いいえ。このツールは時間合算用です。スコア公式はゲーム内イベント基準を確認してください。

加速はいつ使うのがよいですか

関連イベントの時間内に完了するよう調整し、大量使用前にスコア基準を確認するのが安全です。
