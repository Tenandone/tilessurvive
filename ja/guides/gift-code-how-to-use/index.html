タイルサバイバル ギフトコード入力方法

タイルサバイバルのギフトコードは専用入力ページではなく、ゲーム内で入力します。 このページでは、現在有効なコード、常時使用できる常設コード、すでに終了した期限切れコードを分けて整理します。

ゲーム内入力案内 有効 / 常設 / 期限切れを区分 最新コード確認可能
入力場所 プロフィール設定 パッケージ交換
有効コード 期限内で使用可能
常設コード いつでも使用可能
期限切れコード 終了済み履歴

タイルサバイバル ギフトコード入力方法

初めて入力する場合は、下の順番で進めれば大丈夫です。

  1. ゲームに入ったあと、プロフィール → 設定 → パッケージ交換 メニューへ移動します。
  2. タイルサバイバルのギフトコードを大文字小文字までそのまま入力します。
  3. 登録後、メールボックスまたは報酬受取画面でアイテムを確認します。

コードが適用されないときの簡単チェック

下の項目を順番に確認してください。

  • コードの綴りと大文字小文字が正しく入力されているか確認してください。
  • すでに期限切れのコードでないか先に確認してください。
  • アカウントごとに1回制限があるコードか確認してください。
  • 最低レベル条件が必要な場合もあります。

タイルサバイバル ギフトコード FAQ

よく聞かれる内容です。

タイルサバイバルのコードはどこで入力しますか？
ゲーム内のプロフィール設定にあるパッケージ交換メニューで入力します。
常設コードと期間限定コードはどう区別しますか？
いつでも使えるコードは常設コードとして別表示され、期限があるコードは有効コードまたは期限切れコードとして区別されます。
コードが適用されないときは何を確認すればいいですか？
大文字小文字、期限切れかどうか、アカウントごとの1回制限、最低レベル条件を先に確認してください。
期限切れコードも確認できますか？
このページ下部で期限切れコードの記録も一緒に確認できます。
