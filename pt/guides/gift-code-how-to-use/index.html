Como resgatar códigos de presente de Tiles Survive

Os códigos de presente de Tiles Survive são resgatados dentro do jogo, não em uma página oficial separada de resgate. Esta página organiza os códigos ativos, os códigos permanentes e os códigos expirados em seções separadas.

Como resgatar códigos de presente de Tiles Survive

Siga estes passos se estiver resgatando um código pela primeira vez.

  1. Abra o jogo e vá para Perfil → Configurações → Troca de Pacotes.
  2. Digite o código de presente de Tiles Survive exatamente como aparece, respeitando maiúsculas e minúsculas.
  3. Após resgatar, confira sua caixa de correio ou a tela de coleta de recompensas para receber os itens.

Verificações rápidas se um código não funcionar

Confira estes itens um por um.

  • Grafia e uso de maiúsculas no código devem corresponder exatamente.
  • Confira se é um código já expirado.
  • Alguns códigos podem ter uma limite de uma vez por conta.
  • Alguns códigos também podem exigir um requisito de nível mínimo.

Registro de códigos de presente expirados

Os códigos expirados são mantidos aqui como registro de referência.

Perguntas frequentes sobre códigos de presente de Tiles Survive

Perguntas frequentes.

Onde inserir os códigos de Tiles Survive?
Você pode inseri-los no menu Troca de Pacotes, nas Configurações do Perfil do jogo.
Como diferenciar códigos permanentes de códigos por tempo limitado?
Os códigos permanentes são exibidos separadamente, enquanto os temporários são organizados como ativos ou expirados.
O que devo verificar se um código não funcionar?
Confira a grafia exata, maiúsculas e minúsculas, validade, limite de um uso por conta e eventuais requisitos de nível mínimo.
Também posso ver os códigos expirados?
Sim. Você pode consultar os registros de códigos expirados no fim desta página.
