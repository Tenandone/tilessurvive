Escolha um pacote

Salve esta página antes da sua próxima recarga

Use esta página novamente para abrir o mesmo link do parceiro. Salvar nos favoritos é uma ação manual e não garante participação nem recompensa.

Use o comando de favoritos do navegador, normalmente Ctrl+D no Windows ou Cmd+D no macOS.

Antes de pagar

  • Confira o jogo, o pacote, a região, a moeda e o preço final.
  • Forneça somente os dados solicitados pelo processo atual de finalização da compra do LootBar.
  • O prazo de entrega e os métodos de pagamento podem variar; use o suporte do LootBar para problemas com transações.
  • Este é um serviço de parceiro terceirizado, não a página oficial de pagamento do jogo.
  • Os links de afiliados podem apoiar o TilesSurvive.net.
