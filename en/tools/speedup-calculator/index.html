FAQ

What does this calculator do?

It adds speedup item days, hours, and minutes into total minutes, total hours, and a day-hour-minute breakdown.

Does it calculate event scores?

No. This tool is for time totals only. Event score rules should be checked in game.

When should I use speedups?

Try to align completions with the active event window, and check score rules before spending a large amount.
