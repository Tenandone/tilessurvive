FAQ

What does this calculator calculate?

It adds days, hours, and minutes from speedup items and shows total minutes, total hours, and a day/hour/minute breakdown.

Does it calculate event points too?

No. This tool only totals time. Event score formulas must be checked against the current in-game event rules.

When should I use speedups?

It is safer to align completions with an active related event and check the scoring rules before spending large amounts.
