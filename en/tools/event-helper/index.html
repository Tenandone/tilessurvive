Event Helper

Event Helper

Organize event schedules, resources to prepare, and recommended actions so you can claim rewards more efficiently.

Event data will continue to be improved based on live game conditions.

Quick Summary

Start with today’s events, resources to prepare, and recommended actions.

What to Check Today

  • Active events
  • Resources safe to spend today
  • Reward deadline

Resources to Prepare

  • Speedups
  • Hero shards
  • Skill books
  • Gear materials
  • Training, research, and construction resources

Recommended Actions

  • Spend resources when events overlap
  • Use the minimum for standalone events
  • Check reward tiers before spending

Event Type Preparation Table

Each event type has different checks and recommended actions.

Event TypeWhat to CheckRecommended Action
Construction EventConstruction speedups, construction resources, deadlineFocus construction speedups when it overlaps with other growth events
Research EventResearch speedups, research resources, completion timingTime research completions inside the event window
Training EventTroop training amount, training speedups, resources by troop typeFinish training during the event window to secure reward tiers
Hero Growth EventHero shards, EXP items, skill booksUse shards and skill books when overlapping events are active
Gear Upgrade EventGear materials, upgrade materials, reward tiersSave materials normally and spend them during the event window
Summon EventSummon tickets, free summon time, cumulative rewardsClaim free summons and use tickets based on reward tiers

Should I Spend Resources Now?

Use the minimum when only one event is active
Spend heavily when growth and spending events overlap
Check the amount needed for the next reward tier first
Save resources if the next tier is unrealistic
Prioritize growth early on, then event efficiency in mid and late game

Event Preparation Checklist

✓Check the currently active event
✓Check points needed for the next reward tier
✓Confirm which resource type to use
✓Check speedup, shard, skill book, and gear material stock
✓Check the event end time
✓Confirm rewards have been claimed

Note

  • This tool is fan community reference material.
  • Actual event names, rewards, and schedules may vary by server and update.
  • Before using important resources, check the in-game event screen one more time.
