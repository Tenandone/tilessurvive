Tiles Survive Gift Code FAQ

Where do I enter Tiles Survive gift codes?
Tiles Survive codes are entered in the game. Open the gift code entry menu from your profile or settings and register the code there.
Does Tiles Survive have permanent codes?
Yes. Tiles Survive can have both limited-time codes and permanent codes. This page highlights permanent codes so they are easy to identify.
Why might a Tiles Survive code not work?
A gift code may be expired, already used, entered with incorrect capitalization, or limited to one use per account. It is best to paste it exactly using the copy button.

The same expiry time is easier to understand when shown in regional time zones. This page lets you check the next expiring code instantly for Asia, Europe, and America.
