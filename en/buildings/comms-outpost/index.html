Comms Outpost

Help System Reinforcement Capacity

The Comms Outpost lets you exchange reinforcements and timer help with your alliance and friends. The verified level table currently lists timer-help counts.

Planning and use

When alliance help is part of your construction or research plan, compare the next level’s timer helps before deciding the upgrade order.

Before upgrading

Help count and time saved per help are separate values. The count alone does not determine the actual completion time.

Building Overview

Help System Guide

Help Reward

When you help an alliance member with speed-ups, you receive Alliance Silver Coins as a reward.

Help Icon

If a help icon appears above the Comms Outpost, it means an alliance member currently needs help.

Upgrade Effect

Upgrading the Comms Outpost increases both the number of help attempts you can receive and the amount of time reduced per help.
