Каталог питомцев

В заданиях разведки, связанных с питомцами, можно получить яйца, вырастить питомцев и использовать их для поддержки команд героев.

В каждый отряд можно взять одного питомца, не заменяя им героя. Официальное руководство

  • Повторные питомцы превращаются в особые отпечатки для тренировки, повышения доли бонуса и открытия навыков.
  • Бонусы характеристик питомца действуют на всех героев независимо от его участия в отряде. Каждый питомец может одновременно состоять только в одном отряде.
  • Незавершённые задания разведки питомцев обновляются на следующий день. Выполненные задания с неполученной наградой сохраняются до 3 дней.
