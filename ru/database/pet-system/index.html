Система питомцев

В заданиях разведки, связанных с питомцами, можно получить яйца, вырастить питомцев и использовать их для поддержки команд героев.

Краткие сведения

ДоступностьПостепенное открытие по прогрессу State
Как получить питомцевВыполнять задания разведки для получения яиц питомцев
Последняя проверка2026-09-18

Развитие

Выводить и развивать питомцев, давать им имена и открывать облики

Поддержка команды

Развитые питомцы дают характеристики всем героям и поддерживают команды в бою

Доступность зависит от прогресса State. Перед важным развитием проверьте функцию в игре.
