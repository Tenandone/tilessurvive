Пушок

Почему выбран этот кандидат: Герой восстанавливает Здоровье, а у питомца есть бонус к эффекту лечения; их взаимодействие требует проверки.

Необходимые условия
  • Герой должен находиться в отряде, на который распространяется эффект.
  • Модификатор эффекта лечения питомца должен действовать на этот источник лечения.
  • У героя должно быть ниже 50% Здоровья.
  • Указанный навык героя должен быть открыт.
  • Указанный навык питомца должен быть открыт.

Прыг-прыг

Почему выбран этот кандидат: У героя есть эффект при низком Здоровье, а питомец снижает урон обычных атак в соответствующем диапазоне низкого Здоровья.

Необходимые условия
  • Герой должен находиться в отряде, на который распространяется эффект.
  • У героя должно быть ниже 50% Здоровья.
  • Получаемый урон должен быть уроном от обычных атак.
  • Указанный навык героя должен быть открыт.
  • Указанный навык питомца должен быть открыт.
