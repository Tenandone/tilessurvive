Условия применения

Правила усиления героев показаны 2026-10-10 для уровня соревнования 30–30. Не смешивайте с обучением войск или другими диапазонами.

Данные игры для проверки

Легендарный фрагмент даёт 9000, эпический — 1000, редкий — 150. Книга для улучшения навыка — 857, алмаз из покупки набора — 60 очков.

Рекомендуемый порядок

  1. Сверьте тему, уровень соревнования и порог сундука.
  2. Сначала посчитайте запланированное развитие, затем остаток.
  3. Рекомендуем не превышать бюджет ради одних очков.

Пример планирования

Один легендарный фрагмент и десять книг при этих условиях: 9000 + 10 × 857 = 17 570. Это пример плана, не прогноз выдачи награды.
