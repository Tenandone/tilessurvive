Evenemangskalender

Utforska veckomönster och uppdrag. Om du vet när ett mönster börjar kan du koppla det till ditt personliga referensschema.

Evenemangsscheman följer veckovis återkommande mönster. Faktiska scheman kan variera med server och speladministration.

Evenemangsöversikt

Referensregler och personliga planer på ett ställe. Kontrollera evenemanget i spelet innan du använder föremål.

Serverns referensklocka
Din lokala tid

Välj avvikelsen som servern visar, från −14 till +14 i steg om 0.25. Inställningen identifierar inte servern och bekräftar inget schema.

Bekräftade datum

Dessa uppgifter innehåller inget aktuellt schema med bekräftade datum. Mönstren nedan avgör inte vilket evenemang som pågår nu.
