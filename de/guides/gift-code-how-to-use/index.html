Tiles Survive: Geschenkcodes einlösen

Befolgen Sie diese Schritte, wenn Sie einen Code zum ersten Mal einlösen.

  1. Öffnen Sie das Spiel, dann gehen Sie zu Profil → Einstellungen → Paketaustausch.
  2. Geben Sie den Tiles Survive-Geschenkcode genau wie geschrieben ein, einschließlich Groß- und Kleinbuchstaben.
  3. Prüfe nach dem Einlösen dein Postfach oder das Belohnungsfenster, um die Gegenstände abzuholen.

Prüfpunkte, wenn ein Code nicht funktioniert

Gehen Sie durch diese Elemente eins nach dem anderen.

  • Schreibweise sowie Groß- und Kleinschreibung des Codes Sie sollten genau übereinstimmen.
  • Überprüfen Sie, ob es sich um eine bereits abgelaufener Code.
  • Einige Codes können eine Nur einmal pro Konto einlösbar.
  • Einige Codes erfordern möglicherweise auch eine Mindestniveau.

Tiles Survive: Häufige Fragen zu Geschenkcodes

Häufig gestellte Fragen.

Wo gebe ich Tiles Survive-Codes ein?
Sie können sie im Menü Paketaustausch unter Profileinstellungen im Spiel eingeben.
Wie erkenne ich den Unterschied zwischen permanenten und zeitlich begrenzten Codes?
Permanente Codes werden separat angezeigt, während zeitgesteuerte Codes als aktive Codes oder abgelaufene Codes organisiert sind.
Was soll ich überprüfen, wenn ein Code nicht funktioniert?
Prüfe die genaue Schreibweise, Groß- und Kleinschreibung, das Ablaufdatum, eine mögliche Begrenzung auf eine Einlösung pro Konto und die erforderliche Mindeststufe.
Kann ich auch abgelaufene Codes sehen?
Ja. Sie können abgelaufene Codeeinträge unten auf dieser Seite überprüfen.
