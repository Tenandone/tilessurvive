Les missions quotidiennes sont réinitialisées à 00:00 UTC. Les tentatives non récupérées expirent ; celles déjà récupérées peuvent être conservées pendant l’événement.

Chaque allumage donne une récompense aléatoire. Les récompenses de l’objectif commun sont distinctes.

Les récompenses sont récupérables après le déblocage de la messagerie. Les courriers de récompense restent valables 30 jours.

La mission d’achat est facultative. Il n’est pas confirmé que les recharges via le lien partenaire TEN comptent pour cette mission.
