Comment utiliser les codes cadeaux Tiles Survive

Suivez ces étapes si vous utilisez un code pour la première fois.

  1. Ouvrez le jeu, puis accédez à Profil → Paramètres → Échange de packs.
  2. Saisissez le code cadeau Tiles Survive exactement comme il est écrit, en respectant les majuscules et les minuscules.
  3. Après l’utilisation du code, consultez votre messagerie ou l’écran de récupération des récompenses pour recevoir les objets.

Vérifications rapides si un code ne fonctionne pas

Vérifiez ces éléments un par un.

  • Orthographe et casse du code doivent correspondre exactement.
  • Vérifiez s’il s’agit d’un code déjà expiré.
  • Certains codes peuvent avoir une limite d’une utilisation par compte.
  • Certains codes peuvent aussi exiger un niveau minimum requis.

FAQ des codes cadeaux Tiles Survive

Questions fréquentes.

Où saisir les codes Tiles Survive ?
Vous pouvez les saisir dans le menu Échange de packs, sous Profil puis Paramètres dans le jeu.
Comment distinguer les codes permanents des codes temporaires ?
Les codes permanents sont présentés séparément, tandis que les codes temporaires sont classés parmi les codes actifs ou expirés.
Que vérifier si un code ne fonctionne pas ?
Vérifiez l’orthographe et la casse exactes, l’état d’expiration, la limite d’une utilisation par compte et l’éventuel niveau minimum requis.
Puis-je aussi voir les codes expirés ?
Oui. Vous pouvez consulter l’historique des codes expirés en bas de cette page.
