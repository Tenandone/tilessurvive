FAQ

Que rassemble cette page ?

Elle rassemble les outils de TilesSurvive.net, dont l’assistant d’événements, le calculateur d’accélérations, la recherche de récompenses et les pages de données.

Cette page traite-t-elle les recharges ?

Non. Le lien en bas de page est une référence externe pour consulter les avantages avant de préparer les événements.
