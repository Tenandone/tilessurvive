FAQ des codes cadeaux Tiles Survive

Où saisir les codes cadeaux Tiles Survive ?
Les codes Tiles Survive se saisissent dans le jeu. Ouvrez le menu de saisie des codes cadeaux depuis votre profil ou les paramètres et enregistrez-y le code.
Existe-t-il des codes permanents pour Tiles Survive ?
Oui. Tiles Survive peut proposer des codes temporaires comme des codes permanents. Cette page met en évidence les codes permanents pour les repérer facilement.
Pourquoi un code Tiles Survive peut-il ne pas fonctionner ?
Un code cadeau peut être expiré, déjà utilisé, saisi avec une casse incorrecte ou limité à une utilisation par compte. Il est préférable de le coller exactement avec le bouton de copie.
Pourquoi y a-t-il un compte à rebours pour l’Asie, l’Europe et l’Amérique ?
Une même heure d’expiration est plus facile à comprendre lorsqu’elle est affichée dans les fuseaux horaires régionaux. Cette page permet de vérifier immédiatement le prochain code à expirer pour l’Asie, l’Europe et l’Amérique.
