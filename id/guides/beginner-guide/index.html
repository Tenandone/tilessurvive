Sebelum memulai

Panduan ini ditulis untuk pemain yang benar-benar baru di Tiles Survive dan membutuhkan arahan praktis untuk awal permainan.

Menurut saya, banyak pemain seperti saya merasa benar-benar kebingungan pada awal permainan. Karena itu, saya memutuskan menulis panduan awal permainan sesederhana mungkin.

Bagi pemain berpengalaman, ini mungkin bahkan tidak terasa seperti panduan sungguhan. Namun, jika membantu pemain baru menemukan arah sedikit lebih cepat, panduan ini layak ditulis. Bacalah dengan santai.

Tiles Survive saat ini telah membuka hingga Musim 3. Informasi yang tersedia belum terlalu banyak, sehingga sebagian keseruannya adalah mempelajari sendiri sambil bermain.

Bidang pengeluaran utama dalam game ini
  • Pecahan pahlawan dan peningkatan bintang
  • Buku keterampilan
  • Perlengkapan pahlawan
  • Perlengkapan eksklusif untuk pahlawan SSR
  • Semua jenis item percepatan
Peningkatan bintang pahlawan mencapai hingga 10 bintang, sehingga kedalaman investasinya lebih besar daripada yang terlihat sekilas.
Hal pertama yang perlu diingat: jika Anda stres melihat pemain lain tumbuh lebih cepat, game ini lama-kelamaan akan terasa melelahkan. Sebaliknya, bermain sesuai ritme sendiri membuatnya lebih mudah dinikmati untuk waktu lama.

1. Jangan mulai di server lama

Keputusan awal terpenting bukan bahasa atau wilayah, melainkan pilihan server. Awal di server yang buruk dapat menghambat pertumbuhan Anda untuk waktu lama.

Banyak pemain menyarankan server atau aliansi dengan lebih banyak pemain dari wilayah sendiri. Komunikasi memang penting, tetapi pilihan server lebih penting lagi.

Jangan mulai di server lama yang sudah jauh berkembang.

Di server lama, kesenjangan sudah sangat besar. Jika bergabung terlambat, mengejar ketertinggalan menjadi sangat sulit. Kecuali Anda pembelanja sangat besar, hampir mustahil melakukannya secara efisien.

Peringatan: Server lama biasanya sudah memiliki kesenjangan kekuatan yang sangat besar. Bagi sebagian besar pemain, terutama yang bukan pembelanja besar, mengejarnya tidak efisien.

Karena itu, jadikan server baru sebagai titik awal utama. Panduan ini juga ditulis dari sudut pandang server baru.

2. Jika memungkinkan, bergabunglah dengan aliansi peringkat 1 di server baru

“Aliansi peringkat 1” di sini bukan sekadar peringkat tinggi sementara. Maksudnya adalah aliansi dengan kemampuan belanja nyata dan pengaruh jangka panjang.

Ketika menyebut aliansi peringkat 1, maksud saya bukan kelompok yang hanya sementara berada di puncak. Maksudnya aliansi dengan setidaknya satu atau dua pembelanja nyata yang kemungkinan akan terus mempertahankan aliansi di dekat puncak.

Awal permainan bergantung pada informasi. Begitu server dibuka, amati pemain dengan cermat dan secepat mungkin cari tahu siapa yang benar-benar mengendalikan laju kerajaan.

Jika gagal masuk aliansi teratas dan seluruh server sudah dipenuhi perang tanpa henti antarpemain kuat, server itu mungkin tidak layak ditinggali. Bagi pemain biasa, kerajaan damai jauh lebih berharga daripada yang kacau.

Sekalipun sudah mulai di sana, tidak apa-apa memulai lagi di server baru lain jika suasananya cukup buruk. Awalnya mungkin terasa sia-sia, tetapi server baru terus dibuka. Pada akhirnya, menemukan server yang tepat lebih penting.

Jika kamu benar-benar tidak ingin memulai ulang setidaknya cobalah masuk aliansi yang mudah diajak berkomunikasi. Game ini sangat bergantung pada koordinasi, dan komunikasi buruk cepat menimbulkan frustrasi.

3. Mengapa sebaiknya bergabung dengan aliansi yang banyak pemain berbayarnya

Aliansi kuat penting bukan hanya karena kekuatan mentah. Aliansi memengaruhi hadiah, partisipasi acara, efisiensi reli, dan kecepatan pertumbuhan Anda secara keseluruhan.

Alasan bergabung dengan aliansi yang banyak pemain berbayarnya sederhana.

Ketika mereka membeli paket, hadiah aliansi dibagikan kepada anggota lain. Perbedaannya jauh lebih besar daripada yang diperkirakan banyak pemain baru.

Selain itu, pembelanja biasanya lebih memahami game dan lebih aktif dalam acara serta reli. Pada akhirnya, aliansi seperti itu cenderung tumbuh jauh lebih cepat secara keseluruhan.

Seperti kebanyakan game SLG, Tiles Survive kemungkinan akan menambahkan transfer server atau fitur serupa di kemudian hari. Namun, hal itu biasanya tidak langsung terjadi.

Menurut saya, diperlukan sekitar lima bulan di server yang relatif damai untuk membangun fondasi yang baik. Karena itulah pilihan server dan aliansi awal sangat penting.

Memilih aliansi yang kuat

Kamu mendapat hadiah aliansi, partisipasi reli yang lebih baik, dukungan acara lebih kuat, dan jalur pengembangan jangka panjang yang jauh lebih stabil.

Memilih server yang tenang atau lemah

Anda mungkin lebih mudah mendominasi acara belanja individu, tetapi acara lintas server dan tingkat aliansi biasanya menjadi jauh lebih sulit.

Pada akhirnya, ada konsekuensi pilihan: jika tujuan Anda mengambil sebagian besar hadiah acara belanja, server lemah atau sepi dapat cocok. Namun, jika Anda satu-satunya pembelanja nyata di sana, hadiah individu mungkin lebih mudah sementara acara seluruh server dan aliansi jauh lebih sulit.

4. Baik pemain gratis maupun yang sedikit berbelanja, buat akun pendukung sebanyak mungkin

Akun pendukung bukan sekadar sumber daya tambahan. Akun ini menjadi salah satu fondasi terpenting untuk pertumbuhan stabil setelah musim dimulai.

Bagian ini sangat penting.

Baik bermain gratis maupun membelanjakan sedikit, buatlah akun pendukung sebanyak yang mampu Anda kelola. Setelah Musim 1 dimulai, akun tersebut menjadi dukungan andal untuk penelitian dan konstruksi.

Pada awal permainan, konstruksi dan penelitian bisa terasa sangat lambat. Namun, dengan beberapa akun pendukung memasok sumber daya, akun utama Anda tumbuh jauh lebih stabil.

Terutama bagi pemain gratis, usaha itu sendiri menjadi bagian dari kekuatan pengembanganmu.

Nilai sebenarnya dari akun pendukung Fungsinya bukan hanya mengirim sumber daya. Setelah musim dimulai, akun tersebut juga membantu Anda memanfaatkan keuntungan terkait penelitian dan konstruksi. Karena itu, pemain yang menyiapkan akun pendukung sejak awal cenderung unggul kemudian.

5. Jangan gunakan percepatan sembarangan

Pengelolaan percepatan langsung memengaruhi laju pertumbuhan Anda di Tiles Survive. Percepatan umum khususnya menjadi sangat berharga kelak jika digunakan dengan baik.

Tiles Survive sangat mengutamakan penggunaan percepatan yang efisien.

Percepatan digunakan untuk konstruksi, penelitian, pelatihan, penyembuhan, dan berbagai acara. Jika dihabiskan tanpa rencana, Anda akan selalu merasa kekurangan.

Banyak pemain membuang percepatan sejak awal karena ingin segera menaikkan peringkat. Namun, biasanya lebih baik mengambil hadiah dasar acara secara konsisten dan perlahan menambah berlian serta sumber daya.

Percepatan sebaiknya disimpan untuk acara besar agar dapat digunakan sekaligus. Peningkatan bangunan, penelitian, kemajuan bintang pahlawan, dan peningkatan perlengkapan akhirnya berubah menjadi poin. Artinya, waktu dan target Anda sangat menentukan.

Jika bermain gratis, hal ini lebih penting lagi. Setelah terlalu banyak membuang percepatan, biasanya sumber daya akan kurang, dan ketika sumber daya habis, pertumbuhan keseluruhan juga melambat.

Penting: Jangan gunakan percepatan umum untuk semua hal. Terutama, penggunaan percepatan umum untuk pelatihan pasukan tidak disarankan.

Kelak, Anda mungkin memiliki simpanan percepatan umum 200 atau bahkan 300 hari. Meski begitu, percepatan tersebut biasanya lebih berharga untuk penelitian dan konstruksi daripada pelatihan.

Aturan dasarnya: fondasi nyata pertumbuhan akun berasal dari penelitian dan konstruksi, dan di situlah manfaat percepatan umum paling terasa.

6. Tujuan awal pertamamu sebaiknya menaikkan tingkat Pembangkit Listrik

Daripada mencoba meningkatkan semuanya sekaligus, lebih aman menjadikan Pembangkit Listrik sebagai target utama pertama dan membangun fondasi Anda dari sana.

Menurut saya, tujuan besar pertama pada awal permainan adalah menaikkan tingkat Pembangkit Listrik.

Setelah sampai sejauh itu, pada dasarnya Anda telah melewati fase pemula paling awal. Setelahnya, Anda dapat lebih berfokus pada acara dan memilih arah pertumbuhan dengan lebih leluasa.

Tidak perlu terlalu terobsesi dengan konstruksi dan penelitian pada permulaan. Jika akun pendukung disiapkan dengan baik, keduanya menjadi jauh lebih mudah daripada yang terlihat.

Anda juga tidak perlu panik untuk segera mencapai Pembangkit Listrik 30. Setelah musim dimulai, biasanya keadaan lebih mendukung untuk meningkatkannya lebih tinggi.

Tentu saja, itu tetap bergantung pada aliansi yang aktif. Sekali lagi, pilihan server dan aliansi Anda juga berpengaruh di sini.

Ringkasan sederhana Daripada mencurahkan semua sumber daya dan percepatan ke segala hal sekaligus, lebih stabil jika menjadikan Pembangkit Listrik sebagai target nyata pertama dan membangun akun selangkah demi selangkah.

7. Jika pengeluaranmu kecil, ini cara bermain yang baik

Pembelanja ringan mengikuti prinsip utama yang hampir sama dengan pemain gratis, tetapi perlu lebih selektif dalam menentukan penggunaan uang pada awal permainan.

Arah keseluruhan bagi pembelanja ringan tidak jauh berbeda dengan pemain gratis. Pilihan aliansi tetap menjadi faktor terpenting.

Jika tumbuh sedikit lebih cepat daripada rata-rata pada awal permainan, aliansi berperingkat tinggi kadang akan menghubungi Anda lebih dahulu. Jika demikian, bergabunglah dengan aliansi bersuasana baik dan stabil dalam jangka panjang.

Pembelian paket harus dipertimbangkan dengan hati-hati.

Prioritas pembelian awal yang disarankan
  • Kartu bulanan
  • Kartu mingguan
  • Antrean konstruksi awal
Biasanya ini terasa paling efisien pada awal permainan.

Sebaliknya, jika belum memahami sistem game dan mulai membeli secara impulsif, Anda mudah membuang uang untuk paket berefisiensi rendah. Sampai lebih memahami struktur Tiles Survive, lebih aman membelanjakan uang dengan hati-hati.

Ringkasan akhir

Untuk memudahkan pemain baru, berikut rangkuman rapi poin terpenting pada awal permainan.

Panduan ini tidak dimaksudkan sebagai panduan utama yang sempurna, tetapi saya berharap ini membantu pemain baru menghindari kesalahan yang tidak perlu pada awal permainan.

Daftar periksa awal permainan

  • Mulailah di server baru, bukan server lama
  • Jika memungkinkan, bergabunglah dengan aliansi peringkat 1, atau setidaknya aliansi dengan pemain yang banyak membelanjakan
  • Jika server terlalu sering berperang, pertimbangkan serius untuk mulai ulang di tempat lain
  • Buat akun pendukung sebanyak yang mampu kamu kelola
  • Jangan sia-siakan percepatan; simpan untuk acara penting
  • Terutama hindari membuang percepatan umum untuk melatih pasukan
  • Jadikan progres Pembangkit Listrik sebagai target besar pertamamu
  • Jangan panik mengejar Pembangkit Listrik 30 terlalu dini
  • Jangan terlalu stres memikirkan konstruksi dan penelitian pada awal permainan
Satu pengingat terakhir: game ini menjadi melelahkan ketika Anda terus membandingkan diri dengan semua orang. Namun, jika bermain sesuai ritme sendiri dalam aliansi yang baik, Anda dapat menikmatinya untuk waktu sangat lama.
