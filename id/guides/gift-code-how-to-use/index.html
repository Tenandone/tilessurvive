Cara menukarkan kode hadiah Tiles Survive

Ikuti langkah berikut jika kamu menukarkan kode untuk pertama kali.

  1. Buka game, lalu masuk ke Profil → Pengaturan → Penukaran Paket.
  2. Masukkan kode hadiah Tiles Survive persis seperti yang tertulis, termasuk huruf besar dan kecil.
  3. Setelah menukarkan kode, periksa kotak surat atau layar klaim hadiah untuk menerima item.

Pemeriksaan cepat jika kode tidak berfungsi

Periksa hal-hal berikut satu per satu.

  • Ejaan dan kapitalisasi kode harus sama persis.
  • Periksa apakah ini merupakan kode yang sudah kedaluwarsa.
  • Beberapa kode mungkin memiliki batas sekali per akun.
  • Beberapa kode juga mungkin mensyaratkan syarat tingkat minimum.

Catatan kode hadiah kedaluwarsa

Kode kedaluwarsa disimpan di sini sebagai catatan referensi.

Tanya jawab kode hadiah Tiles Survive

Pertanyaan yang sering diajukan.

Di mana saya memasukkan kode Tiles Survive?
Kamu dapat memasukkannya di menu Penukaran Paket pada Pengaturan Profil dalam game.
Bagaimana membedakan kode permanen dan kode berbatas waktu?
Kode permanen ditampilkan terpisah, sedangkan kode berbatas waktu dikelompokkan menjadi kode aktif atau kedaluwarsa.
Apa yang harus diperiksa jika kode tidak berfungsi?
Periksa ejaan dan kapitalisasi yang tepat, status kedaluwarsa, batas sekali per akun, dan syarat tingkat minimum.
Bisakah saya melihat kode yang kedaluwarsa juga?
Ya. Kamu dapat memeriksa catatan kode kedaluwarsa di bagian bawah halaman ini.
