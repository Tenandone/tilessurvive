Bukti dan batasan

Hanya untuk pertempuran regu hero. Tidak ada klaim peningkatan damage, tingkat kemenangan, atau formasi terbaik.

Klien tersimpan mengizinkan satu pet per regu. Aturan lengkap formasi hero dan server saat ini belum terverifikasi.
