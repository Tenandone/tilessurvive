Cómo canjear códigos de regalo de Tiles Survive

Sigue estos pasos si vas a canjear un código por primera vez.

  1. Abre el juego y después ve a Perfil → Ajustes → Canje de paquetes.
  2. Introduce el código de regalo de Tiles Survive exactamente como aparece, incluidas las mayúsculas y minúsculas.
  3. Después del canje, revisa tu buzón o la pantalla para reclamar recompensas y recibir los objetos.

Comprobaciones rápidas si un código no funciona

Revisa estos puntos uno por uno.

  • Escritura del código y uso de mayúsculas debe coincidir exactamente.
  • Comprueba si se trata de un código ya caducado.
  • Algunos códigos pueden tener un límite de una vez por cuenta.
  • Algunos códigos también pueden requerir un condición de nivel mínimo.

Preguntas frecuentes sobre códigos de regalo de Tiles Survive

Preguntas frecuentes.

¿Dónde introduzco los códigos de Tiles Survive?
Puedes introducirlos en el menú Intercambio de paquetes, dentro de Ajustes del perfil del juego.
¿Cómo distingo los códigos permanentes de los de duración limitada?
Los códigos permanentes se muestran por separado, mientras que los de duración limitada se organizan en activos y caducados.
¿Qué debo comprobar si un código no funciona?
Comprueba la escritura exacta y las mayúsculas, el estado de caducidad, los límites de un uso por cuenta y cualquier requisito de nivel mínimo.
¿También puedo ver códigos caducados?
Sí. Puedes consultar los registros de códigos caducados al final de esta página.
