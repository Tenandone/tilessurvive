Calcula los puntos de Carrera armamentística antes de gastar

Cuándo se aplica

Estas reglas de desarrollo de héroes se mostraron el 2026-10-10 para la competición Nv.30–30. No las mezcles con puntos de entrenamiento de tropas ni con otro grupo.

Datos del juego que conviene consultar

Un fragmento legendario otorga 9,000 puntos; uno épico, 1,000; y uno raro, 150. Cada manual usado para mejorar una habilidad de héroe otorga 857; cada diamante obtenido al comprar un lote otorga 60.

Pasos recomendados

  1. Comprueba que el tema actual, el nivel de competición y el umbral del cofre coincidan con tu pantalla.
  2. Calcula primero las mejoras de héroes previstas y después compara la cantidad restante.
  3. Recomendamos respetar tu presupuesto en lugar de comprar solo para conseguir puntos.

Ejemplo de planificación

Utilizar un fragmento legendario y diez manuales en esas condiciones otorga 9,000 + 10 × 857 = 17,570 puntos. Es un ejemplo de planificación, no una predicción de recompensas.
