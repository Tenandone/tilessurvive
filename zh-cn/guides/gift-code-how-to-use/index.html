Tiles Survive 礼包码兑换方法

第一次输入时，照下面顺序操作就可以。

  1. 进入游戏后，前往 个人数据 → 设置 → 礼包兑换 菜单。
  2. 将 Tiles Survive 礼包码包含大小写完整输入。
  3. 完成兑换后，到信箱或奖励领取画面确认道具。
