特权轮盘说明

基本结构
  • 达成 VIP 最高等级后，剩余的 VIP 点数可用于特权轮盘。
  • 特权轮盘中的特殊奖励，包含 王者游戏碎片 与 Player One 碎片，完成对应拼图后会自轮盘中移除。
  • 此为机率型奖励内容，即使参与或购买，也不保证一定能取得特定奖励。
活动规则
  • 共有 王者游戏拼图 与 Player One 拼图 两种，完成后可获得对应外观。
  • 要点亮拼图，必须取得相符的拼图碎片。
  • 拼图碎片与特权徽章都来自轮盘奖励，特权徽章可在特权商店中兑换物品。
  • 特权商店商品每周一 0:00 (UTC) 会刷新。
  • 外观只能兑换一次，兑换后下次刷新起该商品不会再次出现。
